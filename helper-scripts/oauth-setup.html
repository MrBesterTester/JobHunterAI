🔐 OAuth Setup

JobHunter Testing Environment

Click the buttons below to authorize JobHunter to access your email accounts. These tokens will be stored in .env.test for automated testing.

📋 What this does:

  • Gmail: Opens authorization flow → stores tokens in database → extracts to .env.test
  • Microsoft: Opens authorization flow → stores tokens in database → extracts to .env.test
  • Backend must be running on http://localhost:8080
  • After authorizing both, tokens are ready for comprehensive test suite

🔒 Permissions requested:

  • Gmail: gmail.readonly, gmail.modify (read emails, manage labels)
  • Microsoft: Mail.Read, Mail.ReadWrite (read emails, manage folders)
